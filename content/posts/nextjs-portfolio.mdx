# Building a Modern Portfolio with Next.js

Creating a portfolio website has never been easier. In this article, we'll explore how to build a modern, performant portfolio using Next.js 15 with App Router, TypeScript, and Tailwind CSS.

## Why Next.js?

Next.js provides several advantages for building portfolio websites:

- **Fast Performance**: Built-in optimization for images, fonts, and code splitting
- **SEO Friendly**: Server-side rendering and static generation out of the box
- **Developer Experience**: Hot reload, TypeScript support, and great tooling
- **Scalability**: Perfect for starting small and growing with your project

## Setting Up the Project

Start by creating a new Next.js project with the latest features:

```bash
npx create-next-app@latest portfolio --ts --tailwind --app --src-dir
```

## Key Features to Include

### 1. Responsive Navigation

A clean navigation bar that works on all devices is essential. Use Framer Motion for smooth animations.

### 2. Hero Section

Make a strong first impression with an eye-catching hero section that clearly communicates who you are and what you do.

### 3. Project Showcase

Display your best work with high-quality images, descriptions, and links to live demos or repositories.

### 4. Blog Section

Share your knowledge and improve your SEO with a blog. Use MDX for a great developer experience.

### 5. Contact Form

Make it easy for potential clients or employers to reach you with a functional contact form.

## Styling with Tailwind CSS

Tailwind CSS makes it incredibly easy to create a cohesive design system. We used a dark theme with cyan and indigo accents for a modern look.

## Conclusion

Building a portfolio website with Next.js is straightforward and gives you a solid foundation to showcase your work to the world.
